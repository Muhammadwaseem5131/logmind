Optional — add an AI key for an analyst summary

Detection works fully offline without a key. With one, LogMind sends only the findings — never your raw log — to the provider your key belongs to, and adds a written summary. The provider is worked out from the key, so there is nothing to choose. Free Gemini key: aistudio.google.com/apikey · Anthropic: console.anthropic.com.
The key goes to your own local LogMind process and then to that provider, and nowhere else. It is never written to disk by LogMind, never printed to a log line, never put in a URL, and never included in an exported report. It stays in this browser only if you tick Remember; without it the key survives a page refresh but is gone when you close the browser. Delete key removes it from both immediately.
